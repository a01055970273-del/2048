# 고양이 2048

보라색 고양이 테마의 한국어 2048 웹 게임입니다.

## 플레이

방향키 또는 WASD 키로 타일을 움직이세요. 모바일에서는 게임판을 스와이프하면 됩니다. 같은 숫자의 타일이 만나면 합쳐집니다. 최고 점수는 브라우저에 저장됩니다.

## GitHub Pages 배포

저장소의 **Settings → Pages**에서 **Deploy from a branch**를 선택한 뒤 `main` 브랜치의 `/ (root)` 폴더를 지정하세요. 저장 후 잠시 기다리면 다음 주소에서 플레이할 수 있습니다.
